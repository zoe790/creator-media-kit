# Eight visual styles

| ID | Style ID | Visual character | Portrait approach |
| --- | --- | --- | --- |
| 01 | `pink-sticker` | Grey paper, pink rules, green labels, playful stickers | Original photo in a Polaroid-style frame |
| 02 | `pink-scrapbook` | Cream paper, oversized pink lettering, handwritten notes | Layered portrait; original photo works if no cutout exists |
| 03 | `navy-creator` | Navy and white, bold portfolio lettering, large figures | Prominent portrait with readable layered text |
| 04 | `cream-ugc` | Warm white, terracotta accents, serif type, fine borders | Original photo alongside the introduction |
| 05 | `cocoa-retro` | Deep brown, butter yellow, orange, expressive typography | Original photo in a rounded arch |
| 06 | `red-editorial` | Muted cream, red type, thin rules, restrained markers | Framed original photo |
| 07 | `long-table` | Cream, brick red, fine rules, Fraunces/Bricolage type | Portrait and text form a structured cover |
| 08 | `editorial-tri-tone` | Burgundy, pink, yellow, rounded data bars | Layered portrait with legible statistics |

All eight include a dedicated photo-free composition using typography, data, and work samples. Prefer original photos for 01/04/05/06. A cutout can help 02/03/07/08 when available and appropriate, but it is never a prerequisite.

Match the recommendation to the creator's actual work and intended partner. Adjust type size, focus, spacing, and column count while preserving the selected visual direction. Avoid copying another creator's career, location, or identity into a template.

Case cards use equal widths and top alignment. Reduce the default three-column density when screenshots would be unreadable at a mobile viewing size. Keep image proportions and full evidence; do not crop off figures to force equal card heights.

Place confirmed brand marks in a compact strip below cases, normally selecting six by relevance. Keep original colors and visual size consistent; do not add individual logo boxes or a separate full-page logo wall by default.

The bundled `assets/examples/eight-styles-preview.jpg` uses a fictional English-language brief and photo-free layouts. It is a design demonstration, not a real creator portfolio.
